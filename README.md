### `uptime`

**Plarix** — runtime policy enforcement for AI agents.

AI agents have tools. Nothing in any framework governs what they are actually permitted to do at runtime. Plarix builds that enforcement layer.

**Wyatt** is the first product. A daemon that intercepts every tool call an agent attempts, evaluates it against defined policy, and allows or denies it. No exceptions.

**AFB Scanner** is a free GitHub App that scans agent repositories on every PR and classifies security exposures before they reach production.

The taxonomy underlying both:
[AFB Specification](https://github.com/plarix-security/afb-spec) — four failure boundaries that define how agent systems break, mapped to OWASP. Open standard.
